Problem statement - As a student, it can become difficult to keep track of different assignments, deadlines and basic academic information at the same time. Campus Track is developed to provide a simple way to manage student details and academic tasks in one place. The project focuses on making basic student and task management easier through a simple menu-driven Java application. It also helps in keeping track of completed and pending tasks.

Scope of the project - The scope of Campus Track is mainly focused on basic student and academic task management. The current project allows users to carry out the following tasks:
1) View student information
2) View available tasks
3) Search for students using their ID
4) Search for tasks using their title
5) Mark tasks as completed
6) Generate a summary of students and tasks
7) Handle invalid inputs and duplicate records
The project is currently designed as a console-based application. In the future, it can be extended with permanent data storage, a graphical interface and more management features.

Target users - The main targeted users of the project, Campus Track are:
1) Students who want to keep track of their academic tasks
2) Students who want to manage basic academic information
3) Beginners who want to understand how Java can be used to create a practical application
The project is mainly designed for academic and learning purposes.

High-level features:
1) Student Management - The system stores basic student information such as the student's name, ID, course and semester. Users can view student details and search for a student using their ID.
2) Task Management - Users can view academic tasks along with their descriptions, deadlines and completion status. A task can also be marked as completed.
3) Search - The system provides simple search options for finding students and tasks quickly.
4) Report generation - Campus Track generates a basic report showing the total number of students, total tasks, completed tasks and pending tasks.
5) Error Handling - The application handles invalid inputs and prevents duplicate student IDs and task titles.
6) Background Processing - The project also includes a background reporter using Java multithreading to demonstrate how background tasks can be handled.
