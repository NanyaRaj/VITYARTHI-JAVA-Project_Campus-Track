Project title - Campus Track

Overview of the project - Campus Track is a simple Java-based student and task management system. I developed this project to manage basic student information and academic tasks in one place. The project has a menu-driven interface where users can view student details, check tasks, search for students or tasks, mark tasks as completed, and generate a simple report. The main purpose of developing Campus Track was to apply the Java and Object-Oriented Programming concepts that I have learned in a practical project.

Its features are:
1) View all student details
2) View all available tasks
3) Search for a student using Student ID
4) Search for a task using its title
5) Mark a task as completed
6) Generate a summary report
7) Handle invalid user input
8) Prevent duplicate student IDs
9) Prevent duplicate task titles
10) Background report generation using multithreading

Technologies/tools used:
1) Java
2) IntelliJ IDEA
3) Object-Oriented Programming (OOP)
4) ArrayList
5) Exception Handling
6) Inheritance
7) Encapsulation
8) Interfaces
9) Method Overloading
10) Method Overriding
11) Multithreading
12) Custom Annotations

Requirements:
1) Java JDK
2) IntelliJ IDEA or any Java-supported IDE

Steps to install & run the project:
1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure a Java JDK is configured in the project.
4. Open Main.java.
5. Run the Main class.
6. The Campus Track menu will appear in the console.
7. Enter the number of the option you want to use.

Main Menu:
1. Display Students
2. Display Tasks
3. Search Student
4. Search Task
5. Mark Task Completed
6. Generate Report
7. Start Background Reporter
8. Exit
